# Monetization Plan

Honest statement of how AgentArsenal may sustain itself. No promises,
no dates, no hype.

## Today: GitHub Sponsors

`.github/FUNDING.yml` points at `mizazhaider-ceh` on GitHub Sponsors.
Sponsorship is a voluntary way to support maintenance: reviewing
skills, keeping tool versions fresh, running the quality checks. It
buys no influence over content and unlocks nothing gated. Every skill,
agent, brain, playbook, and workflow in this repo is free and open
source under the repo license, and that is not changing.

## Possible future: a pro skill pack

One idea under consideration is a separate, paid "pro" pack: curated
advanced playbooks and scenario packs (for example, full purple-team
exercise kits) sold outside this repo. If it ever happens, the rules
are fixed in advance:

- The core repo stays complete and free. Nothing gets moved behind a
  paywall or hollowed out to make the paid pack look better.
- The paid pack is new, separate content, clearly labeled as
  commercial, with its own license.
- No delivery dates are promised until the content exists and is
  reviewed. Announcements happen after the work is done, not before.

## What this plan is not

- Not a promise that a paid product will exist.
- Not a change to the license of anything already published.
- Not a fundraising target. Sponsors fund maintenance time, not a
  roadmap.

If you want to support the project today, sponsoring on GitHub or
contributing a skill (see `docs/community/CONTRIBUTING_ADVANCED.md`)
both help more than any future plan.

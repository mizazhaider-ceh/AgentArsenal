One arsenal for every agent you run.

AgentArsenal is a unified, machine-inspected library of 246 versioned skills, 25 named operators, 16 reasoning brains, and 47 CLI tools. Every artifact carries a version, a freshness date, and a quality score, so your agent loads procedures you can trust.

Why it is trustworthy

Trust is a build artifact.

Every claim on this page is produced by a script in the repository, not written by hand. The numbers come from the manifest, the validator, and the scorer. Nothing merges on reputation.

  • Per-skill semver versioning, pinnable installs
  • 14-check CI validation harness
  • 0 to 100 quality scoring, 70+ merge gate
  • Validated, acyclic dependency graph
  • Freshness dates on every skill
  • Lifecycle states: experimental, stable, deprecated
  • Installer backs up before every run, with rollback
  • Offline bundles for air-gapped environments

    Agents and brains

    Operators, not prompts.

    A skill is a procedure. An agent is a named operator that binds skills and reasoning brains into a repeatable role, with a memory mode, an escalation policy, and hard constraints it never breaks. Select an agent to inspect its loadout.

    Sixteen ways to think.

    Brains are reusable reasoning patterns. An offensive agent loads attacker-mindset, a reporting agent loads evidence-chain, a design agent loads threat-modeling. Any brain plugs into any agent.

      Composition

      Composition you can audit.

      Skills declare requires, extends, relates, and parent edges. The installer resolves the full closure automatically, and CI fails on a dangling reference or a cycle. This is a real slice of the graph, drawn from the manifest. Select any node to inspect it.

      Quality assurance

      Two gates. Zero vibes.

      validate.py runs 14 checks over every artifact. score.py grades each one 0 to 100 on trigger density, command quality, edge cases, and references. Merge needs 70 or more. Anything red fails the build.

      Experimental

      New skills land here. Usable, watched closely, and clearly marked while they earn trust.

      Stable

      Proven skills with fresh verification dates. The installer copies these by default.

      Deprecated

      Retired but still readable. Excluded from new bundles, never silently deleted.

      The CI workflow

      On every change, the harness runs the checks, grades the work, and enforces the gate. Stale skills surface as build failures, not silent rot.

      validate.py · 14 checks→ score.py · 0 to 100→ gate: 70+→ merge or fail

      Platforms

      One standard, nineteen homes.

      Every skill is a folder with a SKILL.md file, now a cross-platform standard. Pick your agent and the installer copies the arsenal to the exact folder it reads. Paths come from vendor documentation.

      Operations

      Runbooks for the whole engagement.

      Playbooks bind agents, skills, brains, and decision docs into ordered phases with entry and exit criteria, roles and handoffs, stop conditions, and artifacts produced. Workflows coordinate the agents. Tools do the small jobs.

        Four coordination patterns

        pipeline

        Stages in sequence, each feeding the next.

        coordinator-fanout

        One coordinator fans tasks out to workers, then merges.

        reviewer-gate

        A reviewer must approve before the next stage runs.

        evidence-gate

        Claims advance only with attached evidence.

        47 operator tools

        Every tool uses the Python standard library only, accepts --help with examples, and exits 0 on success. Select any tool to copy its run command.

        Installation

        Install the arsenal.

        Clone, preview, install. The installer resolves dependencies from the manifest, backs up your existing skills before touching them, and rolls back on request. Run anything with --dry-run first to see exactly what would be copied.

        Contributing

        Add your own steel.

        New skills pass through the same gates as everything else. Scaffold it, write it to the standard, then prove it.

        1

        Scaffold

        python3 scripts/new_skill.py --domain web --name my-skill

        Generates the folder, the frontmatter, and the body skeleton.

        2

        Write it

        SKILL.md: trigger, Quick Workflow, Edge cases, Key references

        Numbered operator steps with exact commands, plus the defender view.

        3

        Validate

        python3 scripts/validate.py

        All 14 checks must pass. No dangling references, no cycles.

        4

        Score

        python3 scripts/score.py

        70 or higher to merge. The repo average is 95.6.

        House rules: original content only, authorized security work only, simple direct English. No em dashes in content: CI checks for U+2014 and fails the build.

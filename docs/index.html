Questions, answered.

Who is this for?+
Cyber students, pentesters, SOC analysts, developers and researchers. Beginner, practitioner and expert learning paths say exactly where each one starts.
Which platforms does it install on?+
Nineteen, including Claude Code, OpenCode, Gemini CLI, Codex CLI, Cursor and GitHub Copilot. The installer maps each one to the exact directory its agent reads.
Is it free?+
Yes. MIT licensed, free forever: the skills, the installer, the tools, everything.
Can I install a single skill?+
Yes. Install everything, one domain, one skill, or pin a skill to a version. Dependencies resolve on their own, and rollback is built in.
How do I add a skill?+
Open a proposal with the issue template, then run the scaffolding CLI. It generates a perfectly formatted skill, and the validator tells you exactly what to fix before review.
Who keeps the quality up?+
Machines, mostly. The validation harness gates every change, scores rank every artifact, and a freshness check flags stale tooling on a schedule.
